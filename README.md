# Rio's Poker Table

A simple Texas Hold’em table for friends. It uses play chips, not real money.

Open [the game](https://pocket-table-rio-1120.satinbiscuit8.chatgpt.site/), enter your name, and create a table. Send the invite link to your friends. Once they’ve joined, the host can deal.

The game handles turns, bets, and winners. The host can add chips, remove someone from the table, or restart the game.
